# Webpack mastery: Від препроцесорів до аналізатора

## ✨ Функціональність проєкту

- DevServer для автоматичного перезавантаження сторінки при змінах у коді.
- Робота з зовнішніх CSS файлів.
- Підтримка препроцесорів, таких як LESS та Sass/SCSS.
- Компіляція TypeScript файлів.
- Транспіляція JavaScript коду за допомогою Babel.
- Перевірка коду за допомогою Eslint.
- Використання Webpack Bundle Analyzer для візуалізації розміру та змісту пакетів.
