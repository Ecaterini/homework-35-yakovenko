### 4. Інтеграція CSS стилів

- CSS-файли автоматично імпортуються в JS та додаються до DOM під час виконання:

- style-loader

- css-loader

- Підключено нормалізацію стилів:

- import 'normalize.css';

### 5. Оптимізоване використання зовнішніх бібліотек

- Для мінімізації розміру основного бандла використовується:

- optimization: {
- splitChunks: {
- chunks: 'all'
- }
- }
- Також підключено бібліотеку jQuery:

- npm i jquery

- І використано в коді:

- import $ from 'jquery';
